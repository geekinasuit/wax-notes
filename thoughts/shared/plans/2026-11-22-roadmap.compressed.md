  shared code shared/<module>/src/commonMain/kotlin, tests src/commonTest/kotlin; Bazel compiles commonMain as JVM lib today; fork compiles same sources for K/N later
  commonMain uses no java.*|javax.*|android.* API incl. implicit java.lang(System, Thread, String.format); text-scan test guards(#2); HEURISTIC until #7 compiles commonMain for K/N(=real check)
  every lib used from commonMain must publish KMP artifacts incl. iOS(kotlinx-coroutines, kotlinx-serialization…); JVM-only lib only behind a port, from platform/
  platform capabilities(keystore, SQLite driver, WebSocket, signer intents)=interfaces in commonMain, impls in platform/<target>, wired in apps/<target>; no expect/actual until fork supports it(interfaces+constructor injection cover need, simpler)
  tests use kotlin.test, not JUnit APIs directly
  shared Compose UI uses only CMP common APIs, no androidx-only
